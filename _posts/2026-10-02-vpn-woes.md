I don't know who will need this, but I'll put it out there anyway. If it helps one soul, it will have been worth it.

If you are at an institution that uses GlobalProtect for VPN access, you'll notice that the GlobalProtect GUI client has not yet been updated to support Ubuntu 26.04.1 LTS, so you'll have to rely on a CLI.

Well, theirs did not work for me at all, so I resorted to using the CLI from [https://github.com/yuezk/GlobalProtect-openconnect](https://github.com/yuezk/GlobalProtect-openconnect). (Note their GUI is a paid service, but you don't have to pay to use the CLI)

After installation, just run:

```bash
sudo gpclient connect <portal>
```

(The `--browser` flag did not work for me)
